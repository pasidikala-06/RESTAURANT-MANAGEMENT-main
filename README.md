# Restaurant Management System

A full-stack web application that allows customers to explore restaurants, book tables, and manage reservations. It includes separate dashboards for customers, restaurant owners, and administrators.

## Technologies Used
- **Frontend:** React.js, Bootstrap, CSS, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose

## Key Features
- Customer registration and login
- Browse and search restaurants
- Online table reservations
- Track and cancel bookings
- Restaurant owner dashboard
- Approve or reject reservations
- Admin dashboard and user management

## Installation & Setup

**1. Clone the repository**
```bash
git clone YOUR_REPOSITORY_URL
```

**2. Install backend dependencies**
```bash
cd backend
npm install
```

**3. Start the backend**
```bash
node server.js
```

**4. Install frontend dependencies** (in a new terminal)
```bash
cd frontend
npm install
npm run dev
```

**5. Open in browser**
```text
http://localhost:5173
```

## Database
Uses MongoDB. Make sure MongoDB is installed and running before starting the backend.
